# 共用矿洞素材

- `atlas.png` 与 `atlas.json`：岩壁、母岩、木构门框、六种矿物、全部官方摆件、废木、炉骸与植被共用图集。
- `floor.png`：低对比连续地面材质。

素材从已确认的基地风格提取、清理并制作变种，来源与重建方法见 `art-studies/mine-style/README.md`。启动时统一加载，所有普通楼层与群系复用两张贴图；群系着色缓存复用裁片，房间创建时烘焙背景。

扩展普通楼层时配置 `BiomeDef.floorArt`，扩展普通群系时配置 `floorStyle` 与 `sceneStyle`。不要按楼层再增加独立图集或房间绘制器。深窟同样复用底板，特殊沉积和地标以叠层表达。

新增素材使用二倍分辨率，图集仍一次加载。四向门框复用同一裁片和真实门格坐标，通道覆盖完整墙厚；墙体交界以侧墙优先，连续岩面背衬消除裁片透明边缘导致的漏缝。

普通岩石与矿石母材共用精修岩层。正常矿车和侧翻车斗独立绘制并对齐脚底；墙火把包含北／左／右支架和四帧竖直火焰。不可采集的装饰统一用蕨类与地衣，不复用可采集蘑菇轮廓。
