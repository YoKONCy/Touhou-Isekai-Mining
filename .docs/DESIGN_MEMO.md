## 0. 项目概述

以"异界矿洞"为核心的独立 Web 游戏。矿洞位于幻想乡旧地狱，因时空乱流导致各平行世界在此交汇融合。

- **类型**：俯视角 2D 实时动作 RPG + Roguelite 下矿 + 采矿合成 + 房间制随机场景 + 章节式线性任务
- **视角参考**：星露谷物语 / 元气骑士（俯视角 2D）
- **与老项目的区别**：矿洞玩法内**不再使用 LLM**，不做 SillyTavern 式自由叙事
- **素材方针**：绝大部分美术资源用 **Canvas 2D + 现代 Web API 程序绘制**；角色立绘、BGM 等复用异界食堂现有资产
- **长期定位**：矿洞只是未来大游戏的**第一个玩法子模块**，后续将接入幻想乡本土大世界、EraTW+LLM、模拟经营等玩法。本项目架构必须从第一天就为"平台化 + 可插拔模块"做最大预留

### 一句话核心循环

> **打造镐子 → 深入乱流矿洞 → 采矿/战斗/救援 → 撤离（路途事件）→ 基地合成强化 → 挑战更深层**

## 2. 技术方案

### 2.1 技术栈

- **Vue 3 (Composition API) + Vite + TypeScript**
- UI（HUD/背包/合成台/对话框/事件卡/商店）用 Vue DOM；游戏画面用 Canvas
- **游戏内核写成框架无关的纯 TS 模块**
- 矿洞模块内部使用**轻量 ECS**（仅模块内部实现，不上升为平台概念）
- 碰撞：自研 AABB（俯视角无重力）
- 不引入 Phaser / Pixi 等重型引擎；性能真有瓶颈时局部再评估 WebGL2
- 存档：**IndexedDB + Dexie**（不必再背 SQLite-Wasm）
- 后续可选：PWA / Capacitor 打包 Android

### 2.2 Canvas 2D 现代实践要点（2025-2026 主流做法）

1. **多画布分层**：静态瓦片层 / 实体层 / 粒子光效层 / HUD 伤害数字层分离，静态层只在镜头滚动时重绘
2. **离屏 Chunk 预渲染**：矿洞按区块（如 16×16 瓦片）预渲染到离屏 Canvas，运行时只 `drawImage`
3. **视口裁剪（Viewport Culling）**：屏外区块/实体不绘制
4. **OffscreenCanvas + Web Worker**：地图生成、A* 寻路、FOV 计算等重活丢 Worker；渲染也可整体迁入 Worker，主线程只留输入与 DOM UI
5. **资源管线**：`createImageBitmap()` 异步解码；`imageSmoothingEnabled = false` 保像素硬边；按 `devicePixelRatio` 适配高清屏
6. **坐标取整**：`drawImage` 坐标 Math.floor 避免子像素抗锯齿开销
7. **镜头**：普通房间用**房间级切换**（元气骑士式）；Boss 房场地超大，需要镜头跟随玩家（特殊处理）
8. **高弹幕密度性能**：投射物/伤害数字/粒子全部走**对象池**（零 GC）；碰撞用**空间哈希/均匀网格分区**（Spatial Hash），避免弹幕海下 O(n²) 检测；同屏大量弹幕时按纹理图集批量绘制

### 2.3 程序化生成

- **BSP 二分空间分割**：规整矿道与房间（MVP 首选）
- **元胞自动机 / 醉汉漫步**：有机洞窟（部分群系使用）
- **迷宫回溯算法**：坑道网
- FOV：影子投射（Precise Shadowcasting）
- 敌人寻路：A*
- 可参考零依赖库 `dungeon-cartographer` 的实现思路，或自研
- 群系结构差异由生成算法参数表达（BiomePack 数据驱动）

### 2.4 素材策略

- **瓦片 / 矿物 / 掉落物 / 特效 / 怪物（待定）**：全部程序绘制（Canvas 路径 + 渐变 + 噪声生成岩石、矿脉、岩浆、矿石闪烁光点）
- **角色立绘 / BOSS / 剧情 CG**：复用老项目 `battle_sprites/`（100+ 角色战斗立绘）与 `daily_sprites/`（多表情差分）
- **BGM**：复用老项目东方同人曲库（永夜抄系列等 OGG）
- **设定数据**：复用 `src/assets/lorebook/`（20+ 地点、上百角色 JSON 设定）
- **数值底座可改造复用**：`data/spellcards.ts`、`data/items.ts`、`data/buff.ts`、`services/combatLogic.ts`（伤害/暴击/抗性公式）
- **Canvas 经验可参考**：`services/management/IzakayaScene.ts`（48px 网格、纹理管理、主循环）、`components/management/VirtualControls.vue`（手机摇杆）

### 2.5 初步规格建议（待最终确认）

- 瓦片：**16×16**，显示缩放约 3×（逻辑 ~48px）
- 角色比例：约 14×20 高瘦
- 画风混搭：像素场景 + 精美立绘 cut-in / 对话框

## 3. 平台化架构（为未来多玩法扩展预留）

### 3.1 分层：一核多模

```
┌─────────────────────────────────────────────────┐
│  Vue3 UI 壳：HUD/背包/合成/对话/事件卡/商店（DOM层）  │
├─────────────────────────────────────────────────┤
│  玩法模块层（互相零引用，只通过内核通信）              │
│  base 基地 │ mine 矿洞 │ [未来]大世界/EraTW+LLM/经营  │
├─────────────────────────────────────────────────┤
│  共享领域层 shared：物品/库存装备/属性/任务/事件卡/    │
│  配方/角色/时间——所有玩法共用的"游戏规则名词"          │
├─────────────────────────────────────────────────┤
│  平台内核 core：主循环/模块管理/事件总线/输入/音频/    │
│  资产管线/存档分片/2D场景基座（相机·碰撞·交互）        │
└─────────────────────────────────────────────────┘
```

### 3.2 七条关键抽象

1. **模块契约 `IGameModule`**：每个玩法模块只实现 `onEnter / update / render / onExit / save / load`；模块之间**禁止互相 import**，跨模块调用（如矿洞撤离→路途事件→基地）只走事件总线 + 模块切换
2. **统一物品注册表**：矿石、装备、消耗品与未来经营模式的食材、Era 模式道具共用同一套 `ItemDef`（数据驱动 + tags），模块只按 tag 订阅自己认识的东西
3. **属性双层管线**：
   - 基础属性：角色成长点（非战斗向）
   - 派生战斗属性：装备 + 词缀 + 技能 + buff 经 modifier 管线实时聚合
4. **事件卡脚本引擎**：事件 = `触发条件 + 文案 + 选项 + 效果列表(Effects-as-Data)`；效果处理器（给物品/扣血/加 buff/推进任务/切换模块/改剧情 flag）注册表可扩展。**路途事件、剧情对话、支线任务、未来 EraTW 事件共用同一种卡**
5. **群系包 `BiomePack` 数据化**：{ 生成算法参数, 瓦片主题, 矿物 loot 表, 敌人池, 机关机制, 环境滤镜, 事件修饰 }；加新群系 = 加数据包 + 一组程序绘制材质，零代码侵入
6. **2D 场景基座只做一次**：移动、AABB 碰撞、相机、瓦片渲染、交互射线（按 E 对话）由内核提供，基地与矿洞共用，基地即未来大世界的最小原型
7. **存档分片 + 版本迁移**：`角色档案（全局）` + `每模块各自存档切片`；未来新模块上线旧存档原地兼容（继承老项目 migration.ts 经验）

## 4. 核心系统设计

### 4.1 两大场景域

#### 基地（矿洞入口）
- 可走动俯视角小场景，是整个游戏的安全枢纽
- 承载：主线/支线剧情、商店、合成工作台、仓库、驻留 NPC、下行矿洞入口
- **动态生长**：每救回一名少女，基地多一个实体 NPC（店主/锻造师/任务委托人/伙伴候选），从冷清洞口成长为"幻想乡难民营地"
- MVP 可先做最小场景（锻造台 + 洞口），后续扩充
- 技术上作为未来幻想乡大世界的第一个片区验证

#### 矿洞内部
- 房间制随机推进：清场开门 / 找钥匙等具体规则待定
- **房间只有三类**（不区分采矿房/战斗房，矿物在所有房间随机刷新）：
  1. **普通房间**：敌人 + 随机矿脉/采集点 + 偶尔的杂物，是下矿主体
  2. **事件房间**（稀有）：稀有藏品箱、祭坛（祝福/诅咒三选一）、NPC 房间（救援/商人/神秘人）等
  3. **Boss 房间**：场地**非常大**（多屏空间），Boss 战是游戏主打爽点；镜头在房内跟随玩家
- **Boss 并非每次下矿都遇到**：
  - **主线 Boss**：章节绑定、唯一，推动救援主线
  - **随机遭遇 Boss**：可重复遭遇、反复刷取（刷专属素材/装备）
- **素材产出三条线**：
  - 矿脉：全层随机刷新、总量较多、高级矿稀少；前期镐 6~10 下甚至更久才能敲下一块
  - 非矿物采集点：结晶、植物、遗骸、菌菇等群系特色素材（待物品表填充）
  - 敌人掉落：低概率掉落部分素材
- 深度 = 难度曲线 + 素材品位 + 群系解锁轴

### 4.2 群系三大类

| 类别 | 说明 | 示例 | 出现倾向 |
|---|---|---|---|
| **A 原生矿洞** | 无主题基础矿洞 | 岩层、熔岩窟（旧地狱） | 浅层为主，全程打底 |
| **B 幻想乡融合** | 融合幻想乡本土地段 | 魔法森林、雾之湖、迷途竹林、红魔馆、冥界、月都… | 浅层起出现，随深度解锁新主题 |
| **C 异世界乱入** | 平行世界要素跨界 | 战锤 40K 等任意跨界彩蛋（违和感与强度可更高） | 深层概率递增，稀有/彩蛋向 |

- 每个群系 = 独立瓦片视觉主题 + 矿物表 + 敌人池 + 环境机制（如：月都激光炮台、冥界幽灵、熔岩灼热地板）

#### 属性双轨制（修订核心）

> 总原则：**装备是战斗数值的最大收益来源，属性加点只是锦上添花**。

**A. 战斗属性 —— 升级加点 + 装备共同提供**
- 获取方式：角色**升等**获得属性点，玩家自主分配（加点收益刻意压低，避免数值膨胀盖过装备追求）
- 候选项（待最终列表）：力量、**移速**、物理抗性、魔法抗性、生命、灵力、攻速、暴击、**负重**……
- ~~采矿力~~、~~活力/续航~~ **已取消，不做这两个属性**
- 装备/词缀/符卡提供战斗数值的大头
- 升等经验来源待定（击杀 / 采矿 / 任务 / 事件）

**B. 本格属性 —— 仅由事件改变（类比加拿大死亡之路）**
- **不能靠升级或加点获得**，只能通过路途事件、NPC 互动、剧情抉择永久/临时改变（可升可降）
- 候选项（待最终列表）：
  - **幸运**（稀有掉落、事件正面倾向）
  - **口才**（事件判定、议价、劝退）
  - **锻造**（锻造品质/词缀池，与设施等级叠加）
  - **声望**（NPC 态度、支线、可遇人物层级）
  - 号召力（伙伴上限 1→3）等
- 本格属性是**事件卡系统的核心判定依据**：选项成功率 = 属性 + 随机 + 消耗品修正

#### 战斗手感与异常状态

- **闪避**：带无敌帧（i-frame），有冷却 CD（具体帧数/CD 数值后调）
- **元素异常**：不做复杂元素反应体系，统一实现为 **Debuff 状态机**——冰冻、烫伤、麻痹等各是一种可挂载的 debuff（持续时间 + 周期效果 + 解除条件），玩家/伙伴/敌人共用同一套 debuff 组件
- 弹幕密度偏高（前期温和、后期高压），追求流畅动作手感

### 4.5 救援主线与伙伴系统

#### 主线
- 时空乱流将幻想乡少女们卷入矿洞深处
- NPC 获取共**三种入口**：
  1. **路途事件**：属性/选项判定救人
  2. **矿洞场景交互**：牢笼实体、找钥匙、击败看守 BOSS、护送撤离
  3. **击败后归队（新增）**：部分 NPC 本身以 **Boss 身份**占据矿洞——因乱流压制了强者力量，弱者反而膨胀。击败后可收服归队
     - 官方示例：**琪露诺**自认"最强"、拉着不情愿的**大妖精**一起在矿洞当"路霸"拦路挑战，击败后这对活宝加入基地
     - 这类 Boss 可设计成趣味战/双打战，性格梗与弹幕演出结合
- 救回/收服 → 入驻基地成为 NPC，提供商店/锻造/任务/伙伴功能
- 上百个现成东方角色立绘 = 天然"救援图鉴"长期收集目标

#### 伙伴规则
- 每次下矿至多带 **3 名**（人数由号召力成长点决定）
- **全自动 AI**：自主移动、攻击；玩家不微操
- 职能：协同战斗（吸引火力/清怪）、符卡连携（特定组合共鸣技）、后勤辅助（治疗/背包格/照明等专属能力）
- **不参与采矿**
- 战斗风格数据化（灵梦=高机动近身符卡、琪露诺=冰冻控场、荷取=工程炮台…），lorebook 设定喂数值
- **永不永久死亡**：
  - 局内生命归零 = 倒地，可被道具/符卡拉起
  - 主角生命归零 = 本次失败，同行全员**疗养 1 回合**（下轮锁定不可出战）
- 轻养成：个人等级（随出战成长）+ 好感度（专属支线/被动加成/新事件）；**不穿主角装备**，走专属强化线/专属符卡（避免养成黑洞）

### 4.6 失败结算：三档难度核（契约核）

- **形态**：基地可随时切换的"契约核"，每次下矿前自选风险；高档位自带收益加成（掉落率/稀有度/经验↑）

| 档位 | 素材 | 装备 | 货币 | 属性点 |
|---|---|---|---|---|
| **轻** | 本次素材消散 | 保留 | 少量扣除 | 不扣 |
| **中** | 本次素材消散 | 保留 | 少量扣除 | 扣除少量**未分配点** |
| **重** | 本次素材消散 | **遗落倒下层，下次可找回** | 中等扣除 | 扣除部分**未分配点** |

- 已投入的属性 build 永不动（只扣未分配存款）
- 装备遗落在倒下那一层，下次下矿找到"遗落背包"捡回（UnderMine 式）
- 素材当场消散（不可找回）

### 4.7 路途事件（撤离环节）

- 时机：每次**成功撤离**矿洞后、回到基地前
- 次数：大多数 1 次，小概率 2 次
- 形式：加拿大死亡之路车程事件式 —— 情境文案 + 多选项 + 后果结算
- 四类后果（全部要）：
  1. **物资损益**：矿物/金币/消耗品增减、装备损耗
  2. **下矿增减益**：持续到下次下矿的祝福/诅咒/环境影响
  3. **NPC 与内容解锁**：遇到被卷入的少女，判定成功即可救回入驻基地
  4. **纯叙事风味**：平行世界见闻，营造乱流世界观氛围

### 4.8 基地升级系统

- **资源来源**：从矿洞带回的各种素材（矿锭/特殊材料/随机 Boss 掉落等）逐级投入
- **基地等级是大世界的账号级成长**（不下矿时也在变强），升级解锁项示例：

| 升级线 | 效果方向 | 示例（数值待定） |
|---|---|---|
| **营地容量** | NPC 收留上限 | 达到上限后**不再出现可获取 NPC 的事件**，直到扩建扩容 |
| **疗养设施** | NPC 战败疗养速度 | 初级：疗养 3 回合 → 逐级缩短（2 → 1 …） |
| **功能设施解锁** | 合成/锻造能力 | 合成台需基地 2 级、锻造台需基地 3 级；后续高级附魔/分解/冶炼炉等 |
| **仓库** | 仓储格位 | 素材/装备库存上限 |
| **商店/补给** | 商品池刷新与稀有度 | 更好的消耗品、 deeper 层补给 |
| **防御/装饰** | 待扩展 | 可能的离线产出、被动加成等 |

- 基地同时是可走动场景，升级应有**可见的场景变化**（新帐篷/新工位/更多 NPC 摊位），成长感外显

### 4.9 货币与交易体系（余烬 · 火种）

**世界观前提**：幽默风末日 + 时空乱流，旧世界金钱信用早已崩溃。矿洞时代，**能烧的东西才是真钱**——矿洞资源本位，双货币结构。

| 货币 | 定位 | 世界观包装 | 主要产出口（暂定） | 主要消费口（暂定） |
|---|---|---|---|---|
| **余烬** 🟤 | 基础通货 | 矿洞里随处可采的可燃灰烬，矿工拿罐子装、按罐日结；粗糙但人人认 | 矿脉伴生采集、向商人出售素材/装备、普通房杂物、路途事件 | 商店购买消耗品/基础装备、基地低级升级、锻造手续费、补给 |
| **火种** 🔴 | 稀有代币 | 封存于深层的"永燃之火"结晶，象征基地存续的希望——**基地升级 = 留住更多火种** | 随机 Boss 掉落、深层稀有矿脉/事件房、高难度核结算加成、主线/救援奖励 | 祭坛祝福、神秘商人稀有货、符卡获取/升级、顶级锻造、基地高级升级 |

- 未来接入幻想乡大世界时，余烬/火种作为矿洞时代货币可保留或设计兑换过渡
- 具体汇率、掉落数值待物品大表与经济曲线阶段填写

### 4.10 主角身份（双轨开局）

主角身份在新游戏时二选一，**深度影响主线/支线剧情与终局追求**：

**① 普通人（MVP 首发只做这个）**
- 可以是穿越者，也可以是幻想乡本地人，具体出身细节由玩家自由编造
- 剧情线围绕"矿洞幸存者营地 + 救援少女们"展开

**② 失落的至高神（后期版本，沿用异界食堂预设背景）**
- 来自其他平行世界，在时空乱流中意外吸收了**原初创世神的神格碎片**（至高创世神的遗物）
- 神格碎片残留创世神意志，作为神秘"自我指引"暗中引导主角
- 除主角外无人能驱动权柄的真正力量
- 终局追求：收集**五块创世权柄碎片**，集齐合成"完整的神之权柄"（生命/灵力/战斗等级提升至 ∞、本源神力永不枯竭）
- 主线与支线剧情与普通人身份有差异（具体分支待剧情大纲阶段）
- **本期不实现**，但数据结构上预留身份类型字段与权柄碎片特殊物品位

### 4.11 工业管线系统（Round-based Production Line）

基地内的 MC 工业模组式生产网络，负责把矿洞原料加工为材料中间品与装备。**以"下矿回合"为节拍**：主角每次下矿 = 管线运转一个回合，撤离回基地时统一结算。

#### 核心循环
```
回基地 → 往机器/箱子投料、调整产线 → 下矿（管线空转1回合）
→ 撤离路途事件 → 回基地结算："叮——这趟矿的功夫，货好了"
```
冒险时长 = 加工时长，玩家永不干等、永不需要挂机。

#### 设计原则（学什么 / 扔什么）
- **学 MC 工业**：碎矿→洗矿→离心的**副产品倍增链**（高级工艺线让矿石产量翻倍，中后期追求点）；机器速度/产能升级；锭→压缩件的多级压缩；模具/模板锻造
- **扔掉的负担**：电压层级炸机、满地拉电缆的布线地狱、流体管道微观操作、几十上百种机器类型——动作游戏玩家回基地要的是"整备爽"，不是"进厂上班"
- **材料全自动，装备留仪式感**：材料加工/中间品量产可以完全自动化；但**最终装备成型保留手动确认**（亲手放料 → roll 词缀 → 敲下那一锤），不跳过 build 游戏最爽的环节

#### 回合结算模型：流水线稳态
- 每次回基地结算时，物品沿机器网络按**拓扑顺序流动一整轮**，每台机器有"每回合处理 N 件"的吞吐上限
- 新建管线开机有 1~2 回合"注水期"（物料沿管线流动），稳态后**每趟回家都能收到一批成品**
- ❌ 禁止"一件货等四回合"的线性延迟挫败：不做一台机器固定吃 1 回合、四道工序就要跑四趟矿的设计
- 底层数据结构按 **DAG 网络**（机器节点 + 连接边 + 拓扑排序结算）实现，未来加支线/合流/自动化物流只做数据扩展

#### 能源：回合燃料预算
- 发电机每回合燃烧燃料（煤球、岩浆、余烬等矿洞产物）产生本回合**能量预算**
- 机器按工序耗能，预算不足则低优先级机器停转（玩家设定优先级）
- **余烬既是钱又是燃料**："这罐余烬拿去买补给，还是喂炉子？"构成真实资源抉择
- 高级发电方式随科技线解锁（魔网/聚变/零点核心彩蛋向）

#### 物流：前期自动，后期手动
- **前期（T1-T2）**：机器在基地场景内摆放，一定范围内自动连接，箱子即物流节点，轻布局零拉线
- **后期（T3+，高级物流科技解锁后）**：传送带（物品可见流动）、机械臂、分拣网络、总线式供料——给硬核玩家工厂布局深度，不强迫所有玩家使用

#### 失败回合
- 主角倒下的那一回合，管线**空转、0 产出**（叙事："没人看管，炉火灭了"）
- 机器不爆炸不损坏，惩罚温和且与 NPC 疗养一个回合共同构成"回家重整"节奏
- 高难度核是否加重此处惩罚，待数值阶段定

#### 科技解锁：基础看等级，顶级看 NPC
| 层级 | 解锁条件 | 内容举例 |
|---|---|---|
| 基础机器 | **基地等级** | 碎矿机、冶炼炉、工作台（MVP 三台机线性链） |
| 进阶工艺 | 基地等级 + 中级设施 | 洗矿、离心、压缩、模具锻造 |
| **顶级/特色科技线** | **对应 NPC 入驻** | 河城荷取=河童工程机械线；帕秋莉/爱丽丝=魔法炼金线；C 类异世界 NPC=黑科技线（战锤机械神教/月都科技等乱入彩蛋） |
- 救援选择 = 科技路线选择，与救援图鉴系统深度联动
- 群系主题对应机器外观：A 原生蒸汽工业 → B 幻想魔法工业 → C 乱入黑科技

#### MVP 切片（三台机线性链）
```
碎矿机 → 冶炼炉 → 工作台
（原矿）  （锭）    （手动锻造装备）
```
1 台发电机 + 3 台机器 + 燃料预算 + 回合结算，跑通"投料下矿→回家收锭→锻造"闭环后再扩 DAG 支线与自动物流。

#### 架构预留
- 管线系统放在**共享领域层（shared）**而非矿洞/基地模块私有：未来模拟经营模块直接复用整套机器/配方/能源系统，零返工
- 配方 = `输入物品 + 能量 + 时间(回合数) → 输出物品 + 概率副产品`，数据驱动
- 管线存档独立切片（机器布局、库存、能源、物流连接），纳入基地模块存档

#### ItemDef / MaterialDef 数据结构初稿

```ts
type MaterialTier = 'common' | 'rare' | 'advanced' | 'epic' | 'mythic';
//               普通      稀有    高阶      特级    神话

interface MaterialDef {
  id: string;
  name: string;                    // 中文名
  tier: MaterialTier;
  category: 'metal' | 'gem' | 'stone' | 'herb' | 'fungus'
          | 'food' | 'soul' | 'remains' | 'cosmic' | 'special';
  source: Array<'mining' | 'gathering' | 'drop'>;  // 可多来源
  pickTier?: number;               // 镐级门控（矿脉系）
  biomeTags?: string[];            // 出现群系标签
  dropFrom?: string[];             // 特定怪标签 + 概率表
  processRoute?: 'smelt' | 'mill' | 'alchemy' | 'none'; // 管线工艺路线
  fuelValue?: number;              // 燃料热值（可烧物）
  stackSize: number;
  iconKey: string;                 // 程序绘制图标键
  tags: string[];                  // 跨模块订阅依据（如 food/cooking 给经营模块）
  desc?: string;
}
```

- 此结构为统一物品注册表的子集：后续装备/消耗品表到位后向上泛化为 `ItemDef`，字段只增不删
