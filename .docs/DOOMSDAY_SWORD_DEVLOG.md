# 破灭魔王剑开发沉淀

## 1. 目标与定位

破灭魔王剑是仅供开发者控制台获取的隐藏神器，用于测试高伤害武器、复杂状态机、持续附着、范围结算、视觉特效和程序合成音效。

它不进入普通掉落、配方或随机刷怪池。

品质归属为装备品质轴第 5 档「萬象」（DESIGN_MEMO #53）：世界观上它本身就是一片沉积进矿洞的 C 类平行世界切片，"开发者武器"的元属性由此被设定自然消化，无需规格外标签；第 6 档「寰宇」为创世权柄终局系列独占，数值不得逼近。

## 2. 核心玩法规则

### 普通模式

- 左键按住自动挥舞。
- 完整周期 0.5 秒，即每秒两次。
- 前摇 0.08 秒，生效窗口 0.10 秒，后摇 0.32 秒。
- 剑斩基础伤害 666。
- 每次挥砍同时向起手方向发射一道剑气。
- 剑气基础伤害 333，穿墙但不跨房。
- 剑气遇到第一个有效敌人后停止。
- 先造成伤害，敌人存活且未达到上限时植入光刺。
- 每个敌人最多附着六根光刺。
- **插满奖励**：第 6 根植入当帧，若杀戮冷却正在走则削减 2s（`Player.reduceDoomCooldown`，就绪/杀戮中无冷却可减则不反馈）；引爆清空后同一敌人重新插满可再次触发。反馈双通道：敌人头顶大号粉字「杀戮冷却 -2s」+ 脚下充能条 0.5s 纵向脉冲闪辉（`doomsdayCdPulse`）。
- 附着随敌人移动，本房间内永久保留。
- 宿主死亡、玩家换房或模块退出时清理附着。

### 右键引爆

- 必须手持破灭魔王剑，且杀戮冷却已经结束。
- 当前房间至少存在一根有效附着。
- 引爆前先统计全部有效光刺数量 `N`。
- 奖励挥击次数：`6 + Math.min(2, Math.floor(N / 6))`，即 6 根保底 6 次、每满 6 根加 1 次、封顶 8 次。
- 每根光刺对宿主造成基础伤害 666。
- 每个宿主产生一次合并范围冲击，基础伤害为 `333 × 光刺数`，半径 110（含敌方半径）。
- 宿主不重复承受自己的范围冲击。
- 先完成快照，再统一结算；宿主死亡不影响奖励次数。
- 引爆同时触发震屏与冲击环特效（环持续 0.45 秒）。

### 杀戮模式

- 右键引爆后进入杀戮模式，最多持续 8 秒，时间到强制结束。
- 奖励次数为 6～8 次（见右键引爆公式），内部以 8 次硬封顶。
- 按住左键自动连斩（与普通模式同为电平触发，收招帧按住即续下一刀）；仍不缓存攻击以外的额外输入。
- 左右交替挥砍，攻击距离约为普通模式三倍。
- 挥砍节奏为普通模式的 1.2 倍（计时衰减 ×1.2，周期由 0.5s 缩至约 0.42s）；单次动作曲线仍是慢抬手、爆发挥出、急停，只是整体更迅猛。
- 杀戮挥砍基础伤害 3333，范围衰减固定为 1。
- 不发射普通剑气。
- 一次挥击命中至少一名敌人时只消耗一次次数。
- 空挥不消耗次数，也不播放命中音。
- 同次挥击命中多个目标只播放一次主命中音。
- 次数归零、8 秒到时、切换武器、换房或退出模块后结束杀戮。
- 结束后进入 15 秒冷却，冷却期间不能再次引爆进入杀戮。
- 冷却期间仍可使用普通模式，继续发射剑气并积累附着，下次引爆时结算。

## 3. 代码结构

### 物品内容

- `src/content/items/vanilla/weapons/doomsday/index.ts`
  - 注册物品定义、武器槽位、开发者标签和战斗属性。
- `src/content/items/vanilla/weapons/doomsday/melee.ts`
  - 普通挥砍基础数据和节奏。
- `src/content/items/vanilla/weapons/doomsday/icon.ts`
  - 快捷栏 SVG 图标。
- `src/content/items/vanilla/ids.ts`
  - `DOOMSDAY_ID`。
- `src/content/items/vanilla/pack.ts`
  - 加入官方内容包注册。

### 玩家状态机

`src/game/Player.ts` 负责：

- 普通/杀戮模式状态。
- 杀戮剩余次数、8 秒持续倒计时和 15 秒冷却。
- 模式光域过渡值 `doomModeFx`：进入为 +1 并按 `dt*3.2` 衰减回收，退出置 -1 并按 `dt*2.4` 回升。
- 当前挥击快照，避免中途切换武器导致动作跳变；杀戮快照把 `reach` 乘 3。
- 普通模式自动攻击与杀戮模式点按输入分流。
- 杀戮模式左右交替。
- 慢抬手、快速挥击、停刀和缓慢回位曲线；杀戮专用 `doomEmpoweredSweep` 爆发曲线。
- 普通轨迹与杀戮月牙轨迹的生命周期、模式切换光域渲染。

### 房间运行时

`src/game/cave/RoomRuntime.ts` 负责：

- 剑气移动、穿墙和首目标碰撞（线段-圆入口交点排序，防高速穿漏）。
- 每个敌人的光刺附着数组（上限六根，按刺入方向排开）。
- 右键引爆快照、奖励档数计算、宿主伤害和范围伤害。
- 有效挥击计次（杀戮挥砍伤害覆盖为 3333、衰减固定 1）。
- 光束、附着光刺、引爆冲击环的世界层渲染，以及纯图形 HUD（花瓣环、持续时间条、冷却充能条）。
- 换房清理接口 `clearDoomsday`。

### 程序合成音效

`src/game/audio/Sfx.ts` 中神器专用四个入口，均为 WebAudio 实时合成：

- `doomsdaySwing(empowered)`：空挥重音，杀戮档整体放大 1.35 倍。
- `doomsdayBeamHit()`：普通剑气刺入。
- `doomsdayHit(index)`：杀戮命中，带 0.07 秒 gate。
- `doomsdayBurst()`：右键引爆。

### 调试入口

- `CaveModule.debugGiveDoomsday()` / `BaseModule.debugGiveDoomsday()`：控制台获取并装备到 weaponB；原手持武器返还背包，背包满时失败返回 `false`。
- `CaveModule.debugReturnDoomsday()` / `BaseModule.debugReturnDoomsday()`：归还——weaponB 槽置空、背包内所有魔王剑堆抹除（不掉地面），矿洞侧同时 `clearDoomsday` 取消杀戮并清空光束/附着，再 syncMelee 切回武器 A。
- `debugHasDoomsday`（两模块同名 getter）：weaponB 槽或背包存在魔王剑，供控制台单按钮切换判定。**杀戮状态无调试直开入口**——要进杀戮走正式的光刺→引爆链路。
- `CaveModule.debugSpawnDummy()`：在玩家面前 72px 生成 100000 血调试史莱姆（撞墙时扇形找点）。
- `DevConsole.vue`：获取/归还合并为同一按钮（按持有状态切换文案与高亮），另有生成高血靶子等按钮；「塞满开荒物资」「激活杀戮状态」两个旧按钮及其底层方法已移除。
- 调试史莱姆复用蓝史莱姆外观和 AI，仅在调试入口覆盖生命值；不计入 `enemyTotal`，已清房内生成不会重新锁门。

## 4. 视觉开发经验

### 普通剑身

不要用等距锯齿和单一粉色填充模拟原图。原图的辨识点是：

- 非对称倒钩焰刃。
- 深紫/玫红阴影。
- 粉金刃棱。
- 中心较亮但不整把泛白。
- 紫黑护手和玫红晶核。
- 高光应沿刃面移动，而不是固定白线。

### 普通剑气

普通剑气不能画成细线或发光牙签，应使用：

- 厚实的小型柱状光团。
- 圆钝但不规则的前端。
- 紫红外晕、粉色中层、白热核心。
- 微弱流动纹理和柱内闪烁。
- 速度 1400，避免慢悠悠漂浮。

### 普通挥砍轨迹

- 使用由深到淡的轨迹，而不是整块透明扇形。
- 新刃位置最亮，旧轨迹向后衰减。
- 颜色层次：深紫底、玫红中层、粉金边缘、少量白热刃光。
- 轨迹加入稀疏光丝，但不能用大量粒子遮住轮廓。
- 实现锚点：`Player.renderDoomNormalTrail`（由 `renderDoomCrescents` 驱动）。月牙不是描边弧线，
  而是 **52 个环形扇片逐片实体填充**：每片先 `source-over` 铺深紫底（`#60215f`）立轮廓，
  再叠 `lighter` 径向渐变（透明紫 → `#bd258e` → `#f778bf` → 粉白金 `#ffe4c5`），
  最后沿外弧描 1.8px 白金刃口线；截面厚度沿角度正弦展开（普通态中段最厚约 32px：`8+24·sin`）；
  新鲜度 `freshness=exp(-(head-a)*1.8)` 让新刃亮、旧迹指数变暗；半径带 ±2.5% 正弦微扰，避免机械正弧；
  另有 5 缕离刃光丝沿扫过方向继续飘散。

### 杀戮剑身和月牙

杀戮模式参考重型灾厄武器的视觉方向：

- 白热核心。
- 粉紫和玫红能量包络。
- 锐尖、不等宽、向前收束的光刃。
- 动态火舌、裂纹和碎光。
- 月牙应该是宽阔、不均匀、破碎的外弧，不是规整扇形。
- 杀戮轨迹需要更明显的蓄势、爆发和停刀残光。
- 与普通轨迹共用 `renderDoomNormalTrail` 的扇片实填结构，但按 `empowered` 档全面加厚加强：
  底色 `#561653`、截面厚度 `15+70·sin`（中段最厚约 85px）；扫掠角不走匀速，
  用专用曲线 `doomEmpoweredSweep`（先压刀蓄力、中段爆发扫出、末段急停）；
  外弧追加 14 道不规则断裂弧与切向飞散碎光，扩散随时间变化、不得均匀切块。

### 模式切换光域

进入和退出杀戮必须有一眼可辨的状态转折，不能只靠剑身变色：

- 进入时光域向外展开，退出时反向淡回，两个方向用不同速率（展开快、回收慢）。
- 过渡由 `doomModeFx` 单值驱动，靠正负号区分方向，不要维护两套动画时钟。
- 光域与月牙的绘制放在房间光照层之后、`ctx.restore` 之前，否则会被 slice 光照整体压暗。

### 图形 HUD

状态提示全部用 Canvas 图形，不走 DOM 文字：

- 杀戮中：角色右上方（`p.x+23, p.y-25`）八瓣不规则花瓣环，亮瓣数等于剩余次数；瓣片用 skew、微旋转和不匀半径避免排成机械齿轮。
- 花瓣环下方的持续时间条从满到空，表达“消耗”；非杀戮时的冷却条从空到满，表达“充能”，两个方向不能混用。
- 冷却条固定在角色正下方，中心 `p.y+33`：必须让开左下的闪避 CD 圆环，该圆环就绪脉冲放大后底沿约到 `p.y+26`，放到 `p.y+22` 会与之重叠。
- HUD 与世界特效统一用 `'lighter'` 加色混色，靠暗底框（`#26152f`）保证亮条在任何地形上可读。

## 5. 音效开发经验

### 失败原因

早期音效的问题不是单纯高频太多，而是音源结构错误：

- 正弦音过于明显。
- FM 和模态合成形成稳定音高。
- 高频瞬态孤立，像玻璃瓶或塑料玩具。
- 命中尾音太短。
- 低中频虽然存在，但没有成为主体。

降低高频音量只能得到“更闷的玻璃罐”，不能解决根本问题。

### 正确的命中音结构

命中音主体应该是非音高化冲击：

1. 棕噪低通作为厚重底座。
2. 低频宽带下坠，形成砸地和重量感。
3. 中低频扫频，模拟空气被压开。
4. 中高频金属摩擦只作为边缘，不作为主音。
5. 混响尾持续数百毫秒到一秒。
6. 音高层只能埋在轰鸣内部。

### 上行音阶

杀戮最多八次命中，使用暗藏的上行层，但音阶本身只有六级：

- 半音阶：`0, 2, 4, 5, 7, 9`，取值用 `scale[Math.min(5, index)]` 封顶。
- 第 7、8 击钉在最高一级，不再继续抬音，只让非音高轰鸣底层随 index 微量增厚，避免尾刀冲出玻璃高音。
- 音阶层使用低音量三角波，不使用明亮方波或高音正弦。
- 基础频率不能过低，否则上行方向消失；也不能过高，否则产生玻璃感。
- 建议基础频率约 148Hz，并用低通限制。
- 使用极轻的二次谐波增强方向感。
- 后三击（index≥3）逐步压低存在感、二次谐波音量和低通上限，防止高段变成玻璃共鸣。
- 音阶层的作用是“听感上的升级方向”，不能成为独立旋律。

### 空挥音

空挥与命中必须完全分开：

- 空挥：低频嗖轰、宽阔气流、长尾、混响。
- 命中：重砸、实体冲击、金属边缘、长混响。
- 空挥不能包含命中爆鸣。
- 杀戮空挥应比普通挥砍更沉、更长、更有压迫感。

### 参考音频分析流程

对用户提供的参考音频可先执行：

```powershell
ffprobe -v error -show_entries format=duration:stream=sample_rate,channels,codec_name -of default=noprint_wrappers=1 "参考音频路径"
ffmpeg -hide_banner -i "参考音频路径" -af astats=metadata=1:reset=1,ebur128=framelog=verbose -f null NUL
```

重点观察：

- 时长和采样率。
- 峰值与 RMS。
- 响度范围 LRA。
- 是否存在明显稳定音高。
- 低中频是否承担主体。
- 高频是主体还是和声边缘。
- 尾音和混响持续时间。

## 6. 调试与验证经验

高伤害武器不能只用普通小怪测试，因为普通敌人可能被单次伤害直接击杀。应使用 100000 血调试史莱姆验证：

- 普通剑气是否只命中首个目标。
- 同一敌人最多六根附着。
- 光刺是否随宿主移动。
- 右键奖励档数是否为 6/7/8（每满 6 根加 1，封顶 8）。
- 宿主是否避免重复吃自己的范围伤害，范围半径是否约 110。
- 同次多目标命中是否只扣一次杀戮次数。
- 空挥是否不扣次数、不播命中音。
- 最后一击是否仍完整结算全部目标。
- 第 7、8 击命中音是否钉在最高音阶而不出现玻璃感。
- 杀戮 8 秒到时是否强制结束。
- 冷却期间是否：普通挥砍与附着正常、但右键无法再次引爆。
- 换房和切武器是否清理状态。

每次修改后至少执行：

```powershell
npx tsc --noEmit
npx vite build
```

并通过编辑器诊断检查。未进行浏览器试听前，不应声称音效已经完全复刻参考音频。

## 7. 后续维护原则

- 视觉、音频、机制分层修改，避免一次同时改变伤害和表现。
- 普通模式和杀戮模式使用独立的视觉与音效入口。
- 先判断声音是否具有稳定音高，再决定是否使用正弦、FM 或 modal；重型冲击优先使用棕噪和宽带滤波噪声。
- 后段音阶如果出现玻璃感，优先降低二次谐波、低通上限和后段存在感，而不是继续提高低频。
- 所有高光、混响和粒子都要保留主体轮廓，避免叠加后变成一团白色。
- 本文的扇片实填、暗底+加色+白热芯分层、噪声边缘等手法允许被其他角色特效借鉴，
  但粉紫玫红配色为魔王剑专属：借手法不借皮。格林剧团特效的复用记录见 `GRIMM_BOSS_FX_DEVLOG.md`。

### 已知待办

- `doomsdayBurst()` 仍保留 92Hz 正弦和 310Hz modal 音高骨架，尚未按命中音的非音高化原则重做；若实机听感发闷或发脆，参照“正确的命中音结构”改造。
- 图形 HUD 与杀戮光刃/月牙的造型、位置仍以实机反馈为准迭代，改动后同步本文件第 4 节的锚点坐标。
