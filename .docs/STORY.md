## 1. 一句话内核

一个被时空乱流卷进旧地狱深处废弃矿脉的普通人，与力量被压制的博丽灵梦一起，在世界不断折叠沉积的离谱矿洞里**挖矿、捡漏、把失散的同伴一个个捡回营地**——背景是克味末日，日常是欢乐摸鱼。终盘确有一个大 BOSS，但在踢到它之前，大家先把饭吃了。

### 1.1 作品基调（最高创作纪律）**【定】**

- **幽默风味末日，不是严肃升华向。** 世界观可以很厚、很克（深不可测的乱流、被整个折叠的世界、强者被压制到寸步难行），但叙事永远落在角色的日常反应上：再离谱的灾厄，也要先吐槽、先吃饭、先把破烂捡回去。
- **起因不服务"查明真相"主线。** 没有沉重的使命感倒计时；玩家下矿的驱动力是贪（矿与宝物）、好奇（下一层折进来了什么鬼东西）、惦记（把人找回来）。真相靠环境只言片语和角色闲聊自然漏出，不开设定说明会。
- **危机按喜剧节奏包装。** 灵梦被怪群围住，脱困后第一句是饿；魔理沙被"救"时在清点宝物。笑点与角色羁绊是主线，末日是背景板上的烟火。
- 大 BOSS 存在且终盘登场，但具体身份/形态由主人保留，在主人主动揭盅前**不追问、不落文档、不做暗示性伏笔**。

### 1.2 角色喜剧分工与严肃配额 **【定】**

- **主角＝冷面吐槽役**：普通人视角，负责把荒诞拽回地面；对话选项走"……""这合理吗"风，是玩家的代入窗口。
- **灵梦＝摆烂但可靠**：平时嫌麻烦、点菜、蹭仓库；真出事时动作比谁都快。
- **魔理沙＝财迷搞怪**：被冲散后捡破烂捡得乐在其中；"借走不还"担当，情报与稀罕物资渠道。
- 后续登场角色的戏份分工随登场批次再定（琪露诺&大妖精暂不设计）。
- **严肃配额九一开**：只有序章醒来约 30 秒、章尾节点等极少数时刻允许正经说话；单次正经不超过两段对话，立刻被段子接走。

## 2. 舞台设定

### 2.1 地理：旧地狱更深处的废弃矿脉 **【定】**

- 主舞台位于东方设定中**旧地狱的更深处**：被遗忘的矿道网络、旧日工业残迹（简易熔炉、轨道矿车、坑木支架都由此而来），向上可追溯至地灵殿与灼热地狱遗迹——那里如今是大迁移后移民聚居的"热闹上层"（见 §6.3）。
- 与之相对，**幻想乡地面已被时空风暴破坏到几乎无法居住**；全部人口已迁入旧地狱（详见 §6）。
- 矿洞不是一张平面地图，而是**纵向无限向下的沉积层**（对应 roguelite 无限层玩法）；越深，时空越不稳定，卷入的切片越古老、越陌生。

### 2.2 时空乱流与"世界切片" **【定】**

- 异变表现为时空乱流：它把不同世界的**地块整块折叠、沉积进矿层**。群系三分类即由此而来：
  - **A 类（原生）**：旧地狱原生岩层与矿脉；
  - **B 类（幻想乡）**：魔法森林、雾之湖等幻想乡地块连同其上的生物被卷入矿洞，成为可遭遇的矿段；
  - **C 类（平行世界）**：其他世界的碎片，以彩蛋/稀有切片形式出现。
- 切片规则细化（融合要素的合理性来源）：**地块、建筑、物件随切片整体迁移；智慧生物可能在迁移中失散、被困；切片沉积后不稳定，存在再次崩塌/转移的可能**——这解释了"为什么红魔馆的吊灯会在矿洞里"以及"为什么某层矿段会突然消失"。

### 2.2.1 乱流的起因（根设定）**【定基调／BOSS 保留】**

- 乱流本质是**克味的宇宙级事故**：世界在旧地狱深处这一点发生了不可名状的交汇，没有可谈判的肇事者，也不向凡人提供完整解释。它"就是发生了"。
- **终盘存在一个大 BOSS**——但具体为何物由主人保留，属于最高保留项：不写进文档、不做早期暗示伏笔、不按"逐层揭谜"去编排章节。
- 因此废弃矿洞的工业遗迹**只是布景与玩法素材**，不承载"古代封印真相"的叙事任务（前代营地的轻悬念保留，见 §6.4，但它是调味不是主线脊柱）。
- "无限向下挖"在叙事上的意义 = 一路捡破烂一路撞见越来越离谱的切片，顺便看看大家还能凑出什么日子；深度是喜劇冒险的纵深，不是真相倒计时。

### 2.3 乱流压制法则 **【定】**

- 乱流对**强者**有压制效应：境界、神力、大规模符卡规则出力被大幅封减，越强的存在受缚越深；普通人几乎不受影响。
- 叙事功能：①解释灵梦为何会被史莱姆围困；②解释"为什么是主角下矿打怪，灵梦守家"；③给后期"压制解除/找到规则漏洞"留成长空间（可对应基地/科技/仪式系统）。
- 压制不是永久常量：随深度、乱流潮汐、局部锚点而波动。**【提案】**序章中梦想封印之所以能放出，是主角呐喊打断怪群节奏的瞬间，灵梦借隙完成的一次"规则边缘"释放，而非压制解除。

## 3. 主角设定

- **开局二选一：男主 / 女主** **【定】**，同一叙事位、共用全部台词与剧情，性别只改立绘与少量措辞。女主设定为**男主的妹妹**（兄妹关系仅存内部设定，不出现在对外提示词中）；无论谁下场，被乱流卷入的都是"这家人里的一个"。
- **普通人**，无战力光环 **【定】**；被乱流卷入时受冲击，记不清来历，只记得"上面的世界"——出身细节默认留空，供玩家自编 **【定】**。
- 叙事定位：**不受压制法则约束的稳定变量**。在强者寸步难行的矿洞里，普通人的劳作（挖矿、锻造、建造）与勇气（那一声大喊）反而是破局点。
- 成长线：战斗属性点 + 工业管线 + 符卡使用（普通人也能驱动符卡？符札作为消耗品的设定正好兼容），属于"以勤补拙"型。
- **资产现状（2026-10-07）**：男主像素立绘 `public/hero-base.png` 已接入对白（`story.speaker.hero`）；女主立绘编号 F-base（heroine-base.png）待生成，开局选角入口与女主 in-game rig 尚未实装。提示词见 art-prompts.md §七。

## 5. 废弃营地（游戏基地）

- 营地本是一处被废弃的矿工作息点：零散木材、烹饪锅、简易熔炉，看得出曾有人生活过 **【定】**。
- 灵梦在序章前已发现此处并作为短暂落脚点；序章末她判断"查明情况前先待在这里"，搜救魔理沙需要据点，主角需要安身之处——双方**互相利用起步**，营地由此重启 **【定】**。
- 营地外显成长与剧情同构：每救回/收服一名角色，营地多一处生活痕迹（帐篷/工坊/田垄），对应 §4.8 基地升级系统 **【提案】**。
- 灵梦在营地的职能定位 **【定·四职能】**（明确**不是商店店员**）：
  1. **结界守家**：以残余力量维持营地安全结界（解释基地为何无敌袭）；"我在维持结界，很费力，别吵"是她理直气壮瘫在篝火边的官方理由。
  2. **符卡顾问**：普通人驱动符札的法门由她教授；符卡制作/符卡相关升级统一挂她（符卡规则专家，专业对口）。
  3. **进度闲聊锚点**：每次回营地按主线进度给一两句新对话——情报随口漏、吐槽不重样（"又捡一堆破烂回来"）；低成本高回报的叙事投放口。
  4. **祈福位**：洞口出发前"顺手祈个福"，未来祝福/运气系统的接口（本格属性系统拖后，接口先留）。
  - 生活面：饿了直说、不做家务、把仓库当杂物桌；真出事时动作比谁都快（序章已立）。
- **第一章营地内容：修复目标板** **【定】**——篝火旁立破木牌列出设施修复清单，玩家 F 木牌上交**仓库材料**推进修复；修好一项、亮一处、解锁一项功能。**实装顺序与实际数值（2026-10-07，`src/shared/production.ts`）**：
  - 烹饪锅（**石料×30 + 木材×20**）→ 最简**烹饪**：蘑菇汤＝可疑蘑菇×5+木材×3+草药×3；岩盐汤同方+盐岩×1（heal 35，需先在矿洞找到盐）。
  - 工作台（`sidequests/crafting`）→ 即时制作：粗麻线（亚麻×3）、木杖（麻线×3+木材×8）、石矛（木材×6+石料×4+麻线×2+史莱姆球×1）。
  - 简易熔炉（三段修缮：①石料×40+木材×15 ②木材×20+麻线×4+史莱姆球×3 ③耐热风嘴×1+煤×8；风嘴与旧炉残骸在熔炉线矿洞搜索中取得）→ 最简**冶炼**：铜/铁锭＝矿石×3+煤×1，一批最多 8 个，**按下矿回合结算**（回合制管线雏形，详见 DESIGN_MEMO §4.11）。
  - 定位：基地升级树的**最底层**与制作系统的**引子**——不做配方台、不做工业 DAG；同时为自由循环提供短期下矿目标（每趟都有材料 KPI，营地肉眼可见变完整）。
  - 未修复前锅与炉是可调查点：F 弹主角吐槽/灵梦画饼式对白（幽默基调的钩子位）。

## 6. 社会形态：幻想乡大迁移 **【定】**

### 6.1 地面失守与列强合作

- 时空风暴席卷地表后，**幻想乡地面几乎无法居住**（风暴、折叠、气候崩坏）。
- 危局促成了前所未有的列强合作：在**八云紫、八坂神奈子、上白泽慧音、八意永琳、星熊勇仪、圣白莲**等人的指挥与协调下，地面的人类、妖怪、妖精**全体向旧地狱迁移**。
- 曾经只有鬼族聚居的旧地狱，一夜之间挤满了各路移民，热闹得像庙会。

**指挥层分工（设定锚点，也是喜剧素材库）：**

| 角色 | 在迁移中的职责 |
|---|---|
| 八云紫 | 空间调度：以境界通道输送人口与物资（迁移完成后，她在追查深层乱流时**失联**，暗线保留） |
| 八坂神奈子 | 基建与工业：守矢的"奇迹科技力"撑住供水、地热、大型工程；后续工业化的总后台 |
| 上白泽慧音 | 人间之里人类的组织、教育与信息安抚——长期被瞒住的人类骤然接收巨量真相反而崩不住，安抚工作收效甚微（笑点） |
| 八意永琳 | 医疗与防疫：帮移民适应地底环境（瘴气、湿度、暗无天日引发的各种不适） |
| 星熊勇仪 | **地主**：旧地狱是鬼族地盘，勇仪负责腾房、划地、劝服本地住户，是名义上的"地底接待办" |
| 圣白莲 | 混居润滑剂：命莲寺一脉本就主张人妖共处，负责种族纠纷调解（调解日常=种族习惯冲突喜剧） |

### 6.2 地底新生活：怪异但能过

- 适应地底极其艰难，但在强者帮助下**生存已不成问题**；移民们甚至搞起了**地底绿化与大规模农业**（地热田、荧光苔藓作物、蘑菇农场等——农业/烹饪系统的世界观众基础）。
- 社会风味的核心笑料：**老死不相往来的种族突然成了邻居**。天狗在坑道顶发行号外、河童到处拉管线、妖精把公共结界当游乐场、人间之里的大叔一边拒绝相信一边排队领永琳的药。
- 整体气质：荒诞末日下的"热火朝天大杂院"——日子苦，但吵吵嚷嚷地过起来了。这也是商人、货币、工坊、任务委托等一切社会玩法的人口基础。

### 6.3 地理分层：热闹的上层与绕不出去的深层矿洞 **【定】**

- **上层旧地狱**（灼热地狱、地灵殿一带）：新聚居地，相对安全、人声鼎沸，移民社会的主体在这里。
- **深层废弃矿脉**（本作舞台）：位置很深、远离聚居地；风暴后只有调查队、拾荒远征队和被乱流卷进来的倒霉蛋会抵达。
- **关于"出口"的关键设定**：主角的废弃营地与通往上层的出口在**物理距离上并不算远**——真正的问题是矿洞方向紊乱、岔路极绕，加上乱流干扰辨识，走着走着就彻底迷路。所以"回不去"是**迷宫问题不是距离问题**：靠双脚找路近乎不可能，需要工程手段（见荷取线）。
  - 遗留脑洞（主人自认没想好，暂挂 TBD）：为什么灵梦知道方向后不直接凿墙开一条通路？——以后用"乱流使岩层结构不稳定/她力量被压制凿不动/凿了会引来怪"之类的说法补，或者干脆用段子糊过去。
- 旅人和流浪商人的来源由此合理化：远征队的掉队者、同样迷失的移民、被切片冲进来的地底原住民——他们随乱流潮汐偶然抵达这一矿段。
- **旧地狱社会的自由活动场景（上层聚居地）属于中期章节内容，当前不做设计。**

### 6.4 前代营地的悬念 **【提案·轻悬念】**

- 营地的前任主人是谁？去了哪里？锅尚温还是积灰多年？
- 作为**轻量悬念/彩蛋**处理（环境细节、偶发闲聊、路途事件里的旧物），不承担主线揭秘任务，随时可以烂尾成段子——幽默基调下，"可能就是某个比我们早来的倒霉蛋，后来跑路了"也完全可以是最终答案。

### 6.5 余烬与火种（货币）**【提案·待玩法对齐】**

- 物理形态建议：乱流中凝结的能量结晶（余烬=暗红低温碎晶，火种=高纯金橙晶体）；既是钱也是工业燃料，解释"货币为什么能驱动科技"。
- 产出与回收：挖矿精炼副产、怪物核心、事件奖励；回收走基地升级/制作/交易。待经济系统批次细化。

## 10. 前期生存物资与采集规则 **【定】**

> 原则：不做饥饿条、不做口渴条，轻核到底。食物定位＝回血道具 + 营地料理 buff；水只做世界可信度的背景。

### 10.1 木材

- 矿洞内新增三类可敲碎的木料残件：**倒塌坑木堆、废弃枕木、破木箱**。
- 技术形态：**与矿石共享同一套可破坏实体/敲击碎落链路**（命中数次→碎掉掉 1~2 木材），不新做采集机制。
- 视觉上与**承重支架**区分开；承重梁不可敲（试图敲时给灵梦吐槽："你敢敲那根试试，整个洞给你埋了。"）。
- 用途：序章 S10 生火、烹饪燃料、修复目标板/基地升级的基础材料。

### 10.2 水（仅背景）

- **不做水物品、不做水分条、烹饪配方不消耗水**。
- 只做环境交代：墙面渗水痕、滴水点、地下水洼/暗河景观房，维持"地底潮湿世界"的可信度即可。

### 10.3 食物链

- **删除测试链路"史莱姆死亡掉饭团"**；怪物回归掉落矿物/凝液类材料的本职（史莱姆凝液以后给炼金/黑暗料理）。
- 饭团的新身份：开局赠送的 3 个叙事化为**灵梦仅剩的口粮**；稳定米饭要等**荷取入驻、上层商路打通**后；密封罐头等文明食品走**宝箱/奖励房**掉落池。
- **前期主食是蘑菇**（与 §6.2 地底蘑菇农场设定咬合），首批三种：
  | 蘑菇 | 生吃效果 | 备注 |
  |---|---|---|
  | 白蘑菇 | 小额回血，安全 | 烹饪主材（蘑菇汤/烤蘑菇） |
  | 荧光蘑菇 | 微光食材；小幅灵力向回复（数值待批次调） | 荧光蘑菇料理＝灵力方向餐 |
  | 毒红菇 | **误食即扣血 + 吐槽** | 红底白点辨识度高；药理/炼金/异常状态系统的未来接口 |
- 毒效 **v1 即效化**（立刻扣血+飘字/屏幕泛绿，不引入持续 debuff 系统），持续中毒留给未来状态系统。
- **未来扩充**：洞穴怪物（蝙蝠/洞鼠等）实装后掉落怪物肉，食材再丰富——本批不做新怪。
- 蘑菇簇与木料同走敲击碎落链路（木堆在地面、蘑菇簇长墙面，放置规则不同、机制相同）。
- 喜剧基调："今天的晚饭又是蘑菇"是第一章常驻段子；灵梦挑食、毒蘑菇鉴定事故都挂这里。

> **实装现状（2026-10-07）**：命名与上表规划暂未对齐——已有的是**可疑蘑菇**（煮汤主材，不可直接吃）、**香菇**（可即食）、**垂果**（heal 5）、**奇怪凝胶**（三色精英掉，heal 20 但附恶心状态）；蘑菇汤 heal 走烹饪面板。毒效已通过统一状态系统落地（恶心/麻痹/晕眩在 `content/statuses/`）。饭团仍为初始/补给食品。蝙蝠翼等怪物食材线未开。
