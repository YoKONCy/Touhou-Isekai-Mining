# 勇剑沃柏尔开发沉淀

## 1. 目标与定位

勇剑沃柏尔是格林的专武，同时实装为玩家可用的传奇大剑。当前仅通过开发者控制台获取，不加入普通掉落、商店或配方。

- 物品 ID：`touhou:vorpal`（常量 `VORPAL_ID`）。
- 品质与等级定义：`rarity: 4`、`tier: 4`。
- 装备位置：`weaponB`，最大堆叠 1。
- 名称：勇剑沃柏尔。
- 简介：格林的勇剑。黑刃回卷，斩断前路。

它的辨识点是长直黑钢剑身、宽大的回弯刃与旧金护手。主角握持版采用破旧、腐蚀、黑雾萦绕的表现，与格林的武器绘制分别维护。

## 2. 核心玩法与最终数值

| 项目 | 当前值 |
| --- | --- |
| 基础伤害 | 299 |
| 攻击强度系数 | 1 |
| 武器暴击率修正 | 25% |
| 穿透 | 30 |
| 攻击长度 | 120 |
| 完整攻击角度 | 120° |
| 击退 | 300 |
| 僵直 | 0.5 秒 |
| 范围伤害衰减系数 | 1 |
| 前摇 | 0.065 秒 |
| 生效窗口 | 0.105 秒 |
| 后摇 | 0.21 秒 |
| 基础完整攻击周期 | 0.38 秒，约 2.63 次/秒 |

- 按住攻击可连续出招，三段动画与音效循环：横斩 → 逆向回斩 → 重劈。
- 基础周期略快于破灭魔王剑杀戮姿态约 0.417 秒的周期，仍受角色攻速修正影响。
- `melee.arc` 存储的是半角：`60 * Math.PI / 180`，对应完整 120°，不可误写为 120° 半角。
- 数值由初版长度 80、完整角度 100°调整为当前长度 120、完整角度 120°。
- 外围黑暗弧光与碎芒仅为视觉表现，不额外扩大伤害判定。
- 本武器没有额外设计右键技能、剑气、光刺或杀戮状态；不继承魔王剑机制。

## 3. 代码结构

### 物品与注册

- `src/content/items/vanilla/weapons/vorpal.ts`：数值、品质、槽位、标签与物品栏 SVG 图标。
- `src/content/items/vanilla/ids.ts`：`VORPAL_ID`。
- `src/content/items/vanilla/pack.ts`：官方内容包注册。
- `src/content/vanilla/lang/zh_cn.json`：`item.touhou:vorpal.name` 与 `item.touhou:vorpal.desc`。

### 玩家动作与特效

- `src/game/Player.ts`：三段动作、挥砍快照、出刃时触发音效与特效、轨迹生命周期、手臂渲染同步。
- `src/game/art/VorpalSlash.ts`：`vorpalSweep` 动作曲线、程序生成的三套序列帧与 `drawVorpalSlash`。
- `src/game/art/rig/weaponRig.ts`：`drawVorpal(ctx, opts)` 主角握持版剑身与动态黑雾。
- `src/game/art/rig/grimmRig.ts`：格林的武器表现，玩家版本修改不应顺带改变此文件。

### 音效与控制台

- `src/game/audio/Sfx.ts`：`vorpalSwing(segment)` 三段专用 WebAudio 合成挥砍声。
- `src/ui/DevConsole.vue`：`toggleVorpal()` 与“拿取／归还勇剑沃柏尔”切换按钮。

控制台按 F8 或反引号打开。按钮与破灭魔王剑一致，按持有状态切换文案与高亮：拿取时直接装备到武器 B 并切至武器 B，原武器返还背包（背包满则取消并提示）；归还时移除装备与背包中的全部沃柏尔，并切回武器 A。基地、矿洞、试炼均适用。

## 4. 挥砍视觉开发经验

### 参考的正确使用方式

用户提供七张序列帧作为设计思维参考，不直接作为贴图资源。重点不是复制颜色，而是学习：

- 大量几何线条与棱角分明的转折。
- 分离刀痕、长缺口和有组织的留白。
- 主挥砍外围的大尺度分叉弧光。
- 三段挥砍的几何流形、框架与图案各不相同。
- 起势、急斩爆发、停刀、残光消散的时序。

### 失败版本与原因

1. 淡红薄弧：只有小范围月牙，既不具备参考的几何结构，也缺乏爆发。
2. 厚黑厚红刃面：用填色堆重量，导致画面脏、厚、遮挡，设计语言仍平淡。
3. 同轮廓换方向：即便增加缓存帧数，也不能替代真正不同的三段构图。
4. 快速动作中的手臂同步遗漏：持剑臂落后一帧会削弱出刀感，需要在渲染前同步角度。

重量来自蓄势与急停、明确轮廓、音头和时序，不等于大面积涂黑。

### 当前三段构图

- **第一段：折扇裂弧**。五层放射刀痕，外围长折线向外分叉，形成打开的折扇框架。
- **第二段：逆卷交叉**。四层逆卷刀痕、破碎菱形框与交叉裂电，不重复第一段放射构图。
- **第三段：断层重劈**。三层断层刀痕、大尺度锯折弧框、向前贯出的长刺，突出终段压迫感。

色彩采用黑色芯线、暗红包边、少量较亮红色刃棱和节点闪芒。暗色不是整片不透明黑底；填色保持薄、窄、分离。

黑暗弧光以多层线宽实现：外层暗红泛光、中层细亮边、内层黑芯。分叉、断框和锐角长刺负责几何感，短十字闪芒与线屑负责爆发和消散。

### 序列帧与时间

- 每段 18 帧，共 54 帧；画布为 448×448。
- 首次使用某段时生成缓存，后续以 `drawImage` 播放，不把参考图片导入项目。
- 玩家轨迹持续 0.28 秒，以 `age / .28` 驱动帧选择。
- `vorpalSweep` 使用短蓄势、非线性急斩、末段急停；第三段蓄势比例更大。
- 挥砍黑雾保持稀疏，只烘托外沿，避免再次把几何线条遮成厚色团。

## 5. 握持模型与物品栏图标

### 主角握持版

- 保留长直身与宽回刃，剑身有不规则收放，回刃末端更尖。
- 以窄亮脊、宽暗侧面代替覆盖整把剑的光滑亮带。
- 使用固定腐蚀斑片、点蚀、裂纹、缺口、破损护手和断续磨亮刃口。
- 纹理位置固定，不能每帧随机生成，否则会产生闪烁。
- 暗红裂缝只做弱明暗变化，不把剑变成高亮玩具。

### 厚黑雾

握持黑雾与挥砍黑雾的目标不同：前者需要厚实萦绕，后者需要保证线条留白。

- 握持雾团为 16 层，上下交错分布，沿剑身和回刃缓慢翻卷。
- 半径随相位变化，黑色核心与暗红灰外沿形成密度层次。
- 使用连续时间和固定相位，避免逐帧随机抖动。
- 主雾在剑后绘制，细雾丝在剑前，保留剑身辨识度。
- 调整浓度时不能全局加厚挥砍特效。

### 物品栏图标

- SVG `viewBox` 为 84×84。
- 采用与破灭魔王剑同类的斜向大器型、分面金属、细亮刃棱和立体护手。
- 借用构图与材质方法，不借用魔王剑专属粉紫配色。
- 保留黑钢、旧金、暗红裂纹、回弯刃和黑雾底衬。
- 小尺寸优先保证剑身与回刃可读，腐蚀细节不能抢走轮廓。

## 6. 音效结构与维护

`vorpalSwing(segment)` 在出刃时触发，不在按键瞬间提前播放。

- 第一段略偏左声像，第二段略偏右，第三段居中。
- 低频下坠层与低通棕噪建立重量。
- 中频扫频形成气流压开和逆卷方向差异。
- 短促破风噪声提供清晰音头。
- 三角波与低频模态层提供埋在气流中的金属余鸣。
- 第三段低频更深、持续更长，并追加短噪声层。

当前实现仍包含正弦与模态层，不应在文档中误称为完全非音高化音效。若后续出现玻璃感、稳定音高或音头过脆，优先检查音源层次，而不是只增加低频音量。

本入口是挥砍声，不能把空挥与命中反馈混为一谈，也不能因三段音效不同就声称已有三段独立命中音。

## 7. 验证与后续维护原则

本轮迭代执行过 `npx tsc --noEmit` 与 `npx vite build`，通过；存在项目原有包体大小警告。开发过程中未启动服务器、未进行浏览器试听或自动视觉验收。用户在最终握持黑雾与物品图标调整后反馈“可以了”。

后续修改应验证：

- 三段循环在按住攻击时持续正常，切换武器不会错误套用动作。
- 起手方向、手臂、剑身、特效方向同步。
- 判定长度 120，完整角度 120°；外围弧光不额外伤害目标。
- 不同攻速下出刃音效仍与攻击生效时点一致。
- 三段几何构图一眼可分，暗背景与亮背景都可辨识。
- 厚握持黑雾不会遮住主角与剑身关键轮廓。
- 小尺寸物品图标不裁切回刃或柄首。
- 首次生成序列帧是否出现卡顿；需要实测再决定是否预热缓存。

维护约束：

- 数值、动作、特效、音效分层修改，避免为了表现强度暗中扩大判定。
- 不再回退为统一厚月牙、整片黑底或只改旋转方向的三连击。
- 不以“更多帧、更多粒子”替代构图差异与动作节奏。
- 握持版、物品图标和格林版保持武器辨识一致，但材质与表现分别维护。
- 类型检查与构建通过不等于手感、画面或音效已经完成实机验收。
