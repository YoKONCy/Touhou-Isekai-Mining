### 采集契约（已重构）

- **矿格侧**：`MineralDef.hp:[min,max]`（每格生成时随机）+ **`requiredMiningPower: 1|2|3|4|5`**——五档镐门控**已启用**，低档镐敲上去只冒灰石火花、完全不扣 HP（MC 式"铁镐挖钻"）。
- **物品侧拆两字段**：`ItemDef.miningPower`（能不能采）+ `ItemDef.miningEfficiency`（每有效一击扣多少 HP）。非镐武器完全不扣矿格 HP。三档镐现状：锈镐 力1/效10（战斗伤害 9）、铁镐 力2/效14（伤 13）、钢镐 力2/效16（伤 15）。
- **木材** HP 30（`caveNature` 自然摆件），可被任意有效攻击破坏。

### 其他现行规则

- **刷矿门控**＝`MineralSpawn { weight, rooms?, minDepth/maxDepth, minFloor/maxFloor }`：按楼层+深度+房型+权重过滤后归一；**序章视为 floor 0**，池中只有铜铁。
- **盐岩**不参加权重池，走普通岩石的独立替换；**煤**从二层起以 0.3 权重正式入池。
- **采集点类型表与稀有植物全群系低概率规则（#43）仍未做**；四叶草/勿忘我目前是三层/四层的固定层素材，而非全群系低概率规则。
- 死亡结算：身上**材料类**（kind='material'）全部丢失，装备/消耗品/仓库保留；安全撤离随身材料自动归仓。
- 🗑️ **carola 示例 MOD 已于 2026-10-07 删除**：红玉转正官方（`touhou:ruby`/`touhou:mineral_ruby`）后，旧 `mods/carola/`（weight 0.12/minFloor:2 + 已废弃的 `yield/hits` 字段）整目录移除，加载器 glob 自动摘除；现存示例 MOD 仅 `mods/sample`（L1 数据包）。⚠️ 旧存档若持有 `carola:ruby` 物品，读档后背包/仓库查询会撞到未注册 id（存档迁移层暂无 id 映射），必要时需补一条 carola:ruby→touhou:ruby 的存档迁移。

## 已确认的全局规则

- **五档素材 ↔ 五档镐**：
  | 镐级 | 暂定名（命名待定） | 可采素材档 |
  |---|---|---|
  | T1 | 粗制石/骨镐 | 普通 |
  | T2 | 钢铁镐 | 稀有（含金刚石、黑曜石等硬特例） |
  | T3 | 金刚石镐 | 高阶 |
  | T4 | 地狱合金镐 | 特级 |
  | T5 | 零点/创世镐 | 神话 |
- **采集系（植物/菌/果）徒手采集**，无需工具；产量/稀有率由装备词缀、饰品、本格属性（幸运）加成
- 素材来源三类：`挖掘`（镐级门控）/ `采集`（徒手）/ `掉落`（特定怪低概率）
- 深度带：浅层 → 中浅层 → 中层 → 深层 → 超深层 → 乱流核心
- 群系标记：`A` = 原生矿洞群系；`B地` = 幻想乡融合群系（B魔=魔法森林 / B湖=雾之湖 / B狱=旧地狱熔岩 / B冥=冥界 / B月=月都 等）；`C` = 异世界乱入群系

**补充全局规则（2026-09-30 主人第一批批改）**：
- **所有稀有植物**（稀有档及以上的草药/菌菇/花果）：**低概率出现在任意自然生物群系**，不绑定特定群系、无特殊采集要求，徒手采
- **全群系矿脉**：远古遗骸（中层起，纯挖）、赛特斯石英（浅层起，纯挖）、暗影钢（中层起，纯挖）、奥利哈刚（中层起，纯挖）
- **纯掉落**：灵魂结晶（灵体敌人）
- **特殊采集道具**：液态流明、游离态反物质需要**中期合成出的专用收集道具**才能采（道具本身待设计，记入待议清单）
- 银/红/蓝宝石：普通矿洞（A）即可产出
