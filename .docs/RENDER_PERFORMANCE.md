# 弹幕与毛玉酱绘制优化

## 2026-10-08

二阶段同时出现大量梭形弹、分裂弹与滞留毛团，原绘制器每个弹体、每帧重新创建路径与渐变，毛球又逐条描绘毛流。爆弹膨胀传入连续变化的半径，原轮廓 Map 还会持续积累不同半径的路径。

本轮将静态外观改为透明贴图缓存：梭形弹的轮廓、脸和光晕一起烘焙，爆弹光晕与旋转冠分开缓存，膨胀只缩放固定毛球，滞留弹的阴影也烘焙到贴图。毛球本体与表情缓存共享到普通毛玉、头饰和剧情毛球；一次冲刺的完整人物拖影共享一张快照。

通用机制放在 `src/core/rendering/SpriteCache.ts`：两倍采样烘焙、共享绘制入口、条目数量与像素预算双重限制。路径缓存也设数量上限。

弹幕轨迹使用可复用的 Float64Array，按需要扩容；命中先检查轨迹包围盒，再执行原来的分段扫掠。非分裂弹不累计无用行程，未到分裂点不创建空返回数组，无敌期间不执行玩家命中扫掠。实体和特效的过期清理使用 `src/core/collections.ts` 的原地稳定压缩。

`ProjectileDef.renderRadius` 允许声明包含光晕的外观边界。房间根据当前画布变换跳过屏外绘制，仍更新所有弹幕的运动、分裂与碰撞。未声明边界的弹种继续正常绘制，避免截断 MOD 的自定义外观。

本轮保持 BOSS 的血量、技能节拍、弹数、弹速、伤害和存活规则不变。未运行本地游戏测试或性能实测；实际帧率改善幅度由玩家在游戏内确认。GitHub Actions 负责发布构建。
