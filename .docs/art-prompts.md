## 三、统一编辑约束

- 画风保持当前日系赛璐璐微像素质感：清楚的明暗块面、有色轮廓与稳定的细像素边缘，不另加厚涂、矢量平滑或像素滤镜。
- 每次只上传正在编辑的那位角色的正式基准。毛玉酱两张新增图上传BOSS立绘，不上传普通形态去重新设计翅膀。
- 同角色保持同画布、同显示尺度、相近头部落点、腰线和下沿裁切。小幅前倾、后仰、塌肩可以改变动作，不能为了放手势把整个人物缩小。
- 差分只修改该段列出的表情、手臂、头部小幅朝向和上身表演。头发只随姿态轻变，衣服固有色、花纹、帽带、蝴蝶结和光照不重画。
- 手部沿用人物原画风，简洁、结构正确，手掌与拇指可读；双肩、袖子和手臂连接自然。妹妹保持本人的肩线和短外套袖型。
- 闭眼线只占原眼部宽度，短而自然，不拉成贯穿面部的粗弧线。
- 端汤、符札、蘑菇只在对应剧情使用；不把道具加进通用中立或情绪差分。
- 输出单人透明PNG，无场景、文字、边框、水印。画幅和分辨率沿用基准，由出图工具设置；手、袖口、发饰、翅膀完整入画。
- 对话立绘差分不替代Sprite眨眼、战斗动作或加载页祈祷动画。

## 四、兄妹共用的情绪编号

哥哥用 `H-` 编号与 `hero-` 文件名前缀；妹妹用 `F-` 编号与 `heroine-` 前缀。两套逐项对应，不把哥哥立绘改个颜色直接当妹妹。

| 情绪键        | 名称   | 实际用途                     |
| ---------- | ---- | ------------------------ |
| `shock`    | 震惊后仰 | 序章“哈？！”、意外发现、突然被咬之前的惊讶   |
| `rant`     | 无语吐槽 | 日常拌嘴、离谱解释、第四层救援中的连续吐槽    |
| `question` | 疑问追问 | “你是谁”“为什么被绑”“然后呢”“再具体一点” |
| `think`    | 思考分析 | 工作桌配方、冶炼用途、拼接露米娅的叙述      |
| `serious`  | 认真警惕 | 质问绑架者、决定救人、重要承诺和危险提醒     |
| `worry`    | 担心安抚 | 解救后的“没事吧”、查看昏倒的毛玉酱、关心同伴  |
| `smile`    | 温和轻笑 | 完成委托、递食物、鼓励同行、较轻的正向回应    |
| `admire`   | 兴奋赞叹 | 序章后询问梦想封印、“好强！那招叫什么”     |
| `proud`    | 自得邀功 | 修锅、修收音机、完成加工后难得邀功        |
| `dead`     | 认命丧气 | 被分配活计、无奈接受安排、“行吧、算了”     |
| `pain`     | 吃痛护臂 | 第四层露米娅咬手臂的“很痛”“松口”       |

基准负责普通叙说与安静听话；`question` 是主动追问，`think` 是安静推理，`rant` 是无语吐槽；`shock` 是意外，`pain` 是被咬后的吃痛。不能靠一张“死鱼眼”或“震惊”覆盖这几种不同表演。

> **使用纪律（稀缺性就是生命力）**
>
> - 全流程目前只批准以下 **5 个节点**；一个剧情弧最多两张（四层弧的 sd-04 与 sd-05 之间隔着回营转场＋和灵梦认人整段，是弧内收尾彩蛋，不得再加密），相邻两张之间必须隔着完整的玩法段落，绝不在同一段对话里连发。
> - 严肃、惊险、温情节点一律不 Q 化：梦想封印、矿道塌方、BOSS 战败、死亡回营、救援对话中的严肃部分都不碰（四层弧只取咬手臂、打滚两个纯闹剧拍）。
> - 未来预留位：荷取乘钻土机凿墙入场（第二章的第一张 SD CG）；在此之前不新增。
>
> **规格**：3:2 横版（与 1440×960 同比例），建议 2160×1440；完整带背景的非透明 PNG；建议入库 `public/cg/`。每张**底部约 15% 高度留字幕安全区**（背景压暗、纹样减疏），图内不画任何文字、对话框与气泡字。
>
> **画风（与 Title 同族、但 SD 化；不是像素风）**：清爽日系动画赛璐璐 Q 版——平滑干净线条、平涂色块、阴影最多一级；所有角色统一 2\~2.5 头身并保留相对身高差（主角与灵梦同档，露米娅矮约一个头）；人物与主要道具外缘一圈干净的粗白色描边（贴纸白フチ感）；搞笑表演全部符号化（大汗滴、青筋、死鱼眼、方型嘴、冲击线、无语竖点）。背景不画写实场景：单一主题色底＋浅色简化和风纹样（勾云／青海波／麻叶）平铺。
>
