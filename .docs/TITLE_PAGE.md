# 标题页与角色身份

入口是 `main.ts → RootApp.vue`。启动只注册内容与 MOD，标题页不建立新档、不挂载游戏引擎。

## 视觉与流程

- `public/title/background.mp4`：用户提供的“视频2.mp4”转成 H.264、无音轨、快速加载版本；原文件保留。窗口隐藏或离开标题时暂停。
- `public/title/poster.jpg`：从当前视频首帧提取的封面，视频加载或自动播放不可用时展示。
- 背景封面与双缓冲视频统一按窗口等比例铺满，宽高比不同时裁切超出的边缘，不再留左右黑边；菜单按窗口定位。
- 主菜单为无框楷体艺术文字，蓝紫色阴影；选中放大、提亮，出现小光饰与渐隐细线。
- 右下角独立的 GitHub 入口以银紫描边、菱形饰框和图标展示，悬停或键盘聚焦时饰框旋转、图标提亮，点击在新标签页打开项目仓库。
- 选人页用现有哥哥、妹妹立绘，选中放大、恢复亮度并加柔光；没有角色卡片边框。
- 新游戏：选主角 → 命名（最多 12 字，空白沿用“我”）→ 启程 → 序章。
- 新游戏和读档确认后先保留首页与弹窗，用 550ms 淡到纯黑，再卸载首页、加载新档；黑屏至少保持 220ms，场景挂载后用 320ms 显现。过渡期间统一屏蔽按键与点击，标题 BGM 在完全黑屏时停止。
- 只有启程时才创建档案；覆盖自动存档前使用自定义 HUD 确认，保留三个手动记录。
- 读取记录：自动存档及三个手动记录，列出姓名、身份、等级、趟数、最深层与时间。
- 暂停菜单继续提供音量、存读档，新游戏会先回选人页；另提供返回标题。

## 持久化与生命周期

`SaveProfile.character.appearance` 是可选字段，旧档恢复为哥哥；名字使用原有 `character.name`。
控制台切换先加载角色资源，再通过 `persistAppearance` 仅更新主档身份，不覆盖下矿前检查点。
手动保存带上当前身份，读取不同记录分别恢复各自的 sprite、立绘和 CG。

读档后卸载旧玩法树、销毁引擎、调用模块离场、取消对话与相关监听，再绑定新档重建场景。
不再使用浏览器刷新完成读档，也不使用浏览器原生确认框。

`HudConfirm.vue` 统一确认弹窗；`SaveSlotsDialog.vue` 共用存读档页面；`AudioSettings.vue` 共用音量设置。
弹窗包含键盘返回、焦点限制与焦点恢复；全局滚动条采用暗槽和铜片造型。

标题、选人、命名、音量设置、记录摘要、状态提示、确认弹窗及无障碍标签全部通过 `t()` 读取语言键。
界面状态保存语言键而非已翻译文本，切换语言时仍可更新。官方基础内容的中文词条统一存于 `src/content/vanilla/lang/zh_cn.json`，第四层的 15 条词条已并入此文件，注册入口只载入这一份。

`LoopingTitleVideo.vue` 使用两个预加载视频交替播放，备用视频暂停在已解码的首帧；逐帧呈现回调计算尾帧的完整显示时长，到边界后才交接。没有逐帧回调时使用结束事件。取消原先提前 0.2 秒播放和 120ms 叠画，避免截去尾部动作或叠加不同时间的运动而产生短促加速感。

## 首页独立 HUD 主题

`src/ui/title-hud.css` 独立定义首页蓝紫与银白视觉。标题设置、读取记录、覆盖确认分别启用 `theme="title"`；弹到 body 的确认框也携带该主题。
首页弹窗使用暗蓝底、细刻线、银紫文字、无框艺术字操作按钮、晶体滑块和独立滚动条，读取记录采用深蓝记录条。
共用组件的默认主题仍为 `game`，暂停菜单、游戏内存读档和确认框继续使用原来的铜钉纸面样式。
首页所有新增标题和状态文本仍通过 i18n 读取。
首页记录条使用独立的 `title-record-sheet` 类名，避免游戏内 `#app .record-sheet` 纸面材质覆盖深蓝底色。正文与日期提高对比度、字号，空槽不再整体降低透明度；面板采用实色底保证动态背景不影响阅读。
首页音量行固定为标签、滑条和百分比三列；滑条有 28px 的稳定交互区域，菱形由裁切绘制而非旋转原生命中框，百分比保留固定宽度。设置面板固定滚动条预留宽度，悬停和拖动不改变布局。

## 记录重命名

自动档与三个手动档均可通过已有记录旁的“重命名”编辑名称，最多 24 个字符，留空恢复默认槽名。
`SaveProfile.meta.label` 独立于主角姓名；旧档没有该字段时仍显示原有槽名。
重命名只修改元数据，不更新保存时间，不覆盖探索检查点。自动保存与同槽覆盖继续保留记录名，读取手动档时该记录名随主档恢复。
编辑弹窗与当前首页或游戏内主题一致，提示、按钮和错误文案均走 i18n。

## 标题音乐

标题曲为《深邃黑暗迷宮》，项目副本 `public/audio/title/DeepDarkLabyrinth.mp3`。
主菜单、选人与命名、标题内的设置和读取记录共用同一首音乐，单曲自动循环，切换子页面不重播。
开始进入游戏时停止并复位，返回标题后从头播放；与矿洞、基地、BOSS 音乐互斥。
总音量、音乐音量和全局静音统一由现有音乐总线管理，不额外叠加独立播放器。
音乐初始默认音量为 60%；已经保存的用户音量设置继续优先使用。
浏览器限制首次自动出声时，在首次点击或键盘交互时自动解锁播放。
采用的中文提示词与方向记录见 [music-prompts.md](music-prompts.md)。

按用户要求，未启动游戏、未执行本地测试或构建，视觉由用户在游戏内确认。发布构建由 GitHub Actions 自动完成。
