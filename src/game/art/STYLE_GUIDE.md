# 角色画风基准

统一采用幼态可爱的日系像素赛璐璐风格。此规范适用于全体角色，包括男主、紫及成熟、冷淡等气质的角色；各人的个性通过眉眼、姿态、服装与配饰区分。

正式参考档案保存在 `art-studies/references/character-style/`：`rumia-style-reference.png` 为已确认的画风与头脸参考；露米娅确认的四向、场景、立绘与行走面板及循环动图位于 `art-studies/rumia/approved/`。绘制以其中的新正脸和单眼侧脸为准，沿用此前选定的 C 风格。头发分束、外翻与遮挡形成蓬松体积；虹膜明暗、上眼睑弧度和小幅嘴部表情共同表现神态。

角色使用清楚的明暗分块与统一像素网格。侧面必须只露近侧的一只眼睛，五官、鼻尖与下颌同时朝向侧方；背面不显示五官。头部、衣领与身体按颈部锚点连接。

行走保持四向构图，腿脚、肘腕使用同一套骨骼数据，附带小幅身体起伏和衣裙跟随。大图与实际游戏尺寸都需要检查。

露米娅默认微微张嘴；其他角色按各自设定设计表情。毛玉酱本人保持闭嘴，BOSS 形态固定正面；头饰与毛玉小怪保留囧脸。

毛玉酱的具体样板为 `art-studies/references/character-style/kedama-style-reference.png`。沿用其中的紫瞳、卷发轮廓、四颗毛球配饰和裙摆绒边；完整头脸直接取自参考素材，不再用旧几何造型重拼。身体拆分部件后接入同一套骨骼姿态。

毛玉酱两种形态的新立绘位于 `public/characters/kedama-girl/portrait.png` 与 `portrait-boss.png`。BOSS Sprite 追加同款白绒边淡紫羽翼，翅膀在身体后方轻扇，普通形态不带翅膀。

侧面双肩沿纵深重叠，近侧臂位于躯干侧面；背面衣料为居中的完整后背，不能混入原参考的侧身手臂。躯干裁片不得包含手臂、袖口与手指，背向上臂在衣身后，袖口和手单独显示在外侧。

露米娅信息面板与毛玉酱重绘均使用这套规范。其他角色的具体素材后续逐个统一；既有资料中冲突的旧比例、脸部与平滑矢量画风说明不再作为美术基准。

灵梦使用 `art-studies/references/character-style/reimu-style-reference.png`：淡然红瞳、大红蝴蝶结、黄色领巾与分离宽白袖。背面头发须重建居中的完整后脑，避免把侧背参考中的发管、手臂或矩形补片带入背向轮廓。正侧面披发位于衣身后方，背面上臂在衣身后、宽袖在外侧；袖子与躯干分开绘制，沿用同一骨骼步态与序章聚气参数。四向、施法和行走样板位于 `art-studies/reimu/`。

男主使用 `art-studies/references/character-style/player-style-reference.png`：半垂眼、黑紫乱发与弯呆毛、开襟蓝羽织、印花白 T 恤、宽松黑裤与运动鞋。正侧面头脸直接沿用 Edit 参考，衣料须保留赛璐璐折面与原花纹；袖筒以完整轮廓承接纹理，不能直接把斜垂袖裁成孤立三角。肩部和臂长沿用武器握点协议，衣身与四肢分别绘制，腿部比例按新参考调整。四向、表情、行走、同框及动作检查样板位于 `art-studies/player/`。

自动眨眼只能改变眼部，不得整张切换开心或其他表情头图。闭眼与默认帧的发型、脸形、嘴部、锚点和透明轮廓须逐像素一致；侧面也应只闭合近侧眼睛，背面无需眨眼。普通呼吸和发摆继续由骨骼姿态驱动。

妹妹采用 `art-studies/references/character-style/sister-style-reference.png` 及用户提供的独立立绘：白贝雷帽、蓝丝带、水手领与蓝白宽袖、百褶裙、高筒袜和深色鞋。主角切换仅选择 Sprite 与对白立绘，共用哥哥的骨骼和武器握点。四向、表情、行走与动作样板位于 `art-studies/sister/`。

哥哥的 T 恤下缘与活动裤腿必须由完整裤腰、胯部衔接；妹妹使用立绘的宽袖、白色袖缘和露出的小臂，不能复用哥哥的长袖轮廓。袖缘覆盖肘部接缝，武器握点与臂长协议保持一致。持镐姿态及腰部连续性检查见 `art-studies/shared/render-body-repair.cjs`。
